# Compatibility

BeamSplit is a public beta. Its self-contained x64 build does not require a separate
.NET installation.

| Area | Known status |
|---|---|
| Windows 11 x64 | Actively developed and tested |
| Windows 10 x64 | Supported; clean-machine community verification requested |
| BeamNG 0.38.5 | Tested during development |
| Other current BeamNG versions | Expected; BeamMP matching is version-aware |
| 2 XInput controllers | Primary tested configuration |
| 3–4 controllers | Supported; wider hardware coverage requested |
| One keyboard plus controllers | Limited by Windows focus; not fully isolated |
| Solo / local BeamMP | Supported |
| OnlineFix/DRM replacements | Not supported or distributed by BeamSplit |

Controllers that expose both XInput and DirectInput can vary by firmware and mode.
Include the exact model and selected mode in compatibility reports.
