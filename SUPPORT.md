# Support

1. Update to the newest release and reproduce once.
2. Open the integrated Console and choose **Create support bundle**.
3. Inspect the ZIP, then attach it to a GitHub bug report with the exact BeamNG version,
   controller models, monitor arrangement, and the point where launch failed.

The bundle redacts known AuthKey formats and the current Windows profile path. Do not
post credentials. Security reports belong in GitHub's private vulnerability form.
